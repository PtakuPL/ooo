## A. BEZPIECZEŃSTWO — Ochrona plików launchera

### Problem
`launcher_config.json` leży obok exe i zawiera `api_base_url` z IP/domeną serwera.
Gracz może otworzyć plik, znaleźć IP i użyć go do DDoS.
`launcher.lock` (PID) leży w `launcher_data/` — mniejsze ryzyko, ale nadal widoczny.

### A1. Ochrona launcher_config.json
**Plik:** `crates/common-models/src/launcher_config.rs`
- [x] Przenieść wrażliwe dane (zaadresowane przez A3: domena zamiast IP) (api_base_url) do zasobu binarnego (embed w exe)
- [x] Lub: zaszyfrować config symetrycznym kluczem wkompilowanym w binary (obfuscation, nie pełne security)
- [x] Minimalna wersja: zamienić `launcher_config.json` na format binarny (MessagePack/CBOR) z obfuscacją
- [x] Zostawić w JSON tylko dane nie-wrażliwe (channel, launcher_data_dir, profile)

**UWAGA:** To jest obfuscation, nie pełne zabezpieczenie — zdeterminowany reverse-engineer i tak znajdzie URL.
Prawdziwa ochrona to CDN/proxy (Cloudflare) przed publicznym IP serwera.

### A2. Ukrycie launcher.lock
**Plik:** `apps/launcher-tauri/src/main.rs` (linia ~42)
- [x] Lock file już jest w `launcher_data/` — OK
- [x] Dodać atrybut hidden na Windows (`FILE_ATTRIBUTE_HIDDEN`) po utworzeniu pliku
- [x] Na Linux: plik zaczyna się od `.` → zmienić na `.launcher.lock`

### A3. Domena tibia.reddaxe.pl zamiast IP
**Decyzja usera:** Używać `tibia.reddaxe.pl` jako domena API.
- [ ] Skonfigurować DNS: `tibia.reddaxe.pl` → IP serwera
- [x] W `launcher_config.json` default: `https://tibia.reddaxe.pl/apik/v1/`
- [x] W kodzie Rust `launcher_config.rs` zmienić domyślny URL
- [ ] Opcjonalnie: Cloudflare/proxy + SSL cert dla domeny
- [ ] **To jest osobny task infrastrukturalny, nie launcher-code**

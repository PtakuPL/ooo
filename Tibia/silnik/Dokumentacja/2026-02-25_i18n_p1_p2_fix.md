# Fix P1 (done_contract stale guard) i P2 (brakujące klucze) — 2026-02-25

## Problem P1: ES/server.json blokowany przez guard_placeholder=10

### Diagnoza
- `done_contract` dla `es/server.json` miał `guard_placeholder=10`, co blokowało status `is_done`.
- Audyt pliku ES/server.json pokazał **0 faktycznych** problemów z placeholderami — wszystkie zapisane tłumaczenia poprawne.
- Przyczyna: done_contract liczył **odrzucone próby tłumaczenia** z GT (transient failures), a nie stan zapisanych tłumaczeń.
- System ochrony placeholderów (`_protect_placeholders` → `__PH0__` tokeny → GT → `_restore_placeholders`) działa poprawnie — potwierdzono testami end-to-end.
- 128 wpisów w `deferred_translation_queue.jsonl` to historyczne próby z poprzednich uruchomień.

### Rozwiązanie
Zmieniono evaluację done_contract (Section 12.2 w `i18n_worker_simple.sh`):
- **Przed**: `cond1_ok = (guard_placeholder == 0 and guard_pipe == 0)` — oparte na metrykach batcha
- **Po**: File-state audit — skan WSZYSTKICH zapisanych tłumaczeń za pomocą `token_sets()`:
  - `_file_audit_ph` — rzeczywiste błędy placeholder w pliku
  - `_file_audit_cmd` — rzeczywiste błędy command w pliku
  - `_file_audit_pipe` — rzeczywiste błędy pipe w pliku
- Metryki batcha zachowane jako informacyjne (`batch_guard_placeholder`, `batch_guard_command`)
- Done_contract teraz używa `source: "file_state_audit"` zamiast transient batch metrics

### Efekt
- `es/server.json`: `is_done=true`, `guard_placeholder=0`, `guard_command=0`
- Wyeliminowano fałszywe blokady done_contract spowodowane przejściowymi błędami GT

## Problem P2: 20,495+ brakujących kluczy

### Diagnoza
- Worker działał z `--translations-only` co pomijało fazę SYNC
- Brakujące klucze: `items.json` (19,676 kluczy) i `npc.json` (819-1053 kluczy)
- Dotyczyło 8 języków: es, ro, it, fr, de, pt, nl, cs (PL i RU już kompletne)
- Łącznie 164,662 brakujących kluczy

### Rozwiązanie
- Ręczny sync skryptem Python: dodanie brakujących kluczy EN jako `[LANG] original_text` placeholdery
- Klucze posortowane alfabetycznie dla spójności
- Backup `deferred_translation_queue.jsonl` (27,084 starych wpisów) → wyczyszczony

### Efekt
- Wszystkie 8 języków: 74,308+ kluczy, 0 brakujących
- Done_contracts zaktualizowane z file-state audit

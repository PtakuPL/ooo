Pobierz Launcher

Aktualna wersja launchera jest wymagana do logowania i aktualizacji klienta.

Pobierz launcher (Windows)

Wymagania: Windows 10/11, WebView2 Runtime.

 

Instrukcja instalacji

  1. Pobierz plik launchera.
  2. Uruchom launcher i zaloguj się na konto.
  3. Launcher sam pobierze lub zaktualizuje pliki klienta.
  4. Kliknij Graj, aby uruchomić grę.

Problemy z uruchomieniem? Upewnij się, że antywirus nie blokuje launchera i że WebView2 jest zainstalowany.

## 1. KONTEKST I PROBLEM

### 1.1 Stan obecny
- Bootstrap (`launcher-bootstrap.exe`, ~1-2 MB) instaluje pliki do wybranego folderu
- Po instalacji w folderze lądują: launcher exe, `launcher_config.json`, folder `client/`
- **Brak jakiejkolwiek deinstalacji** — gracz nie może usunąć launchera przez "Dodaj/Usuń"
- **Brak wpisu w rejestrze** — Windows nie wie, że coś jest zainstalowane
- **Brak skrótów** — gracz musi ręcznie szukać exe na dysku
- Gracz, który zainstalował launcher ze złą konfiguracją, nie ma czystego sposobu odinstalowania

### 1.2 Wymagania użytkownika
1. Bootstrap sam siebie NIE usuwa — użytkownik ściąga go z neta (1-2 MB) i sam decyduje co z nim zrobić
2. Bootstrap MUSI umieć usunąć WSZYSTKO co zainstalował (launcher + config + dane)
3. Musi być OSOBNA opcja usuwania plików gry (client/) — gracz może chcieć zostawić launcher a usunąć grę
4. Przy instalacji gracz wybiera JEDEN folder — gry lądują w podfolderze launchera
5. PRZED instalacją: jeśli wykryta istniejąca instalacja → pytanie "Chcesz odinstalować wszystko?"
6. Wpis w "Dodaj/Usuń programy" Windows → też musi umieć odinstalować WSZYSTKO
7. Musi działać na istniejącej (źle skonfigurowanej) instalacji

## 2. ARCHITEKTURA INSTALACJI

### 2.1 Struktura folderów (po instalacji)
```
C:\Users\Gracz\AppData\Local\SerwerCanary\    ← install_dir (wybrany przez gracza)
├── launcher-tauri-windows-x86_64.exe          ← główny launcher
├── launcher_config.json                       ← konfiguracja API
├── launcher-bootstrap.exe                     ← kopia bootstrapu (= uninstaller)
├── language.conf                              ← preferencja języka
├── launcher_data/                             ← dane launchera (sesje, cache, logi)
│   ├── logs/
│   └── cache/
├── client/                                    ← pliki gry Tibia
│   ├── otclient.exe
│   ├── data/
│   ├── modules/
│   └── ...
└── WebView2/                                  ← Tauri WebView data (opcjonalnie)
```

### 2.2 Co bootstrap zapisuje podczas instalacji
| Co | Gdzie | Opis |
|---|---|---|
| Pliki launchera | `install_dir/` | Exe, config, dane |
| Pliki gry | `install_dir/client/` | Klient Tibia |
| Kopia bootstrapu | `install_dir/launcher-bootstrap.exe` | Służy jako uninstaller |
| Wpis rejestru | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\SerwerCanary` | "Dodaj/Usuń" |
| Skrót pulpit | `%USERPROFILE%\Desktop\SerwerCanary.lnk` | Opcjonalny |
| Skrót menu Start | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\SerwerCanary.lnk` | Automatyczny |
| Preferencja języka | `install_dir\language.conf` | Wybrany język |

### 2.3 Wpis w rejestrze "Dodaj/Usuń"
Klucz: `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\SerwerCanary`

| Wartość | Typ | Treść |
|---|---|---|
| `DisplayName` | REG_SZ | `SerwerCanary Launcher` |
| `UninstallString` | REG_SZ | `"C:\...\SerwerCanary\launcher-bootstrap.exe" --uninstall` |
| `InstallLocation` | REG_SZ | `C:\...\SerwerCanary` |
| `DisplayIcon` | REG_SZ | `C:\...\SerwerCanary\launcher-tauri-windows-x86_64.exe` |
| `Publisher` | REG_SZ | `SerwerCanary` |
| `DisplayVersion` | REG_SZ | `1.0.0` |
| `NoModify` | REG_DWORD | `1` |
| `NoRepair` | REG_DWORD | `1` |

## 4. FLOW DEINSTALACJI

### 4.1 Wywołanie przez `--uninstall`
```
launcher-bootstrap.exe --uninstall
    │
    ├─ Detekcja języka (z install_dir/language.conf)
    │
    ├─ MessageBox: "Na pewno chcesz odinstalować SerwerCanary?"
    │   "Usunięte zostaną: launcher, pliki gry, skróty, ustawienia"
    │   [TAK]  [NIE]
    │   │
    │   ├─ NIE → zamknij
    │   └─ TAK ↓
    │
    ├─ Zamknij działający launcher (jeśli uruchomiony)
    │
    ├─ Usuń pliki gry (client/)
    │
    ├─ Usuń pliki launchera (exe, config, dane)
    │
    ├─ Usuń skrót z pulpitu
    │
    ├─ Usuń skrót z menu Start
    │
    ├─ Usuń wpis z rejestru
    │
    ├─ Usuń folder instalacji (jeśli pusty)
    │
    ├─ MessageBox: "Deinstalacja zakończona."
    │   "Plik bootstrap w folderze pobrań możesz usunąć ręcznie."
    │
    └─ Zamknij
```

### 4.2 Z "Dodaj/Usuń programy" Windows
Windows wywołuje `UninstallString` → `launcher-bootstrap.exe --uninstall`
→ ten sam flow co 4.1

### 4.3 Przed nową instalacją (pre-install cleanup)
Jeśli bootstrap wykryje istniejącą instalację i gracz wybierze "Odinstaluj":
→ wywołanie wewnętrzne `uninstall()` → czyszczenie → zamknij

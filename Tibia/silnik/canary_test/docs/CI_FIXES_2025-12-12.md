## 📦 Canary Server (Linux Build)

### Problem 1: `'localtime' is not a member of 'fmt'`
**Plik:** `src/utils/tools.cpp`
**Błąd:** GCC14 wymaga explicit include dla `fmt::localtime`
**Rozwiązanie:** Dodano `#include <fmt/chrono.h>` (linia 24)

### Problem 2: `'DEFAULT_LOCALE' was not declared`
**Pliki:** `src/config/config_enums.hpp`, `src/config/configmanager.cpp`
**Błąd:** Brak klucza konfiguracyjnego dla domyślnego locale i18n
**Rozwiązanie:**
- Dodano `DEFAULT_LOCALE,` do enum w `config_enums.hpp` (między `DEFAULT_DESPAWNRANGE` a `DEFAULT_PRIORITY`)
- Dodano `loadStringConfig(L, DEFAULT_LOCALE, "defaultLocale", "en");` w `configmanager.cpp`

### Problem 3: `cannot convert '<brace-enclosed initializer list>' to vector`
**Plik:** `src/creatures/players/player.cpp` (linia 5959)
**Błąd:** GCC14 nie pozwala na niejawną konwersję `string_view` → `string` w initializer_list
**Rozwiązanie:**
```cpp
// Przed:
std::vector<std::string> { it->second }
// Po:
std::vector<std::string> { std::string(it->second) }
```

### Problem 4: `reference to 'json' is ambiguous` (wcześniejsza sesja)
**Plik:** `src/utils/i18n/translator.hpp`
**Błąd:** Forward declaration `namespace nlohmann { class json; }` konfliktuje z rzeczywistą definicją
**Rozwiązanie:** Zamieniono na `#include <nlohmann/json_fwd.hpp>`

### Problem 5: `constexpr array with filesystem::path` (wcześniejsza sesja)
**Plik:** `src/utils/i18n/translator.cpp`
**Błąd:** `std::filesystem::path` nie jest literal type, nie może być w `constexpr`
**Rozwiązanie:** Zmieniono `constexpr std::array` na `const std::array`

## 📱 Android SonarCloud Analysis (`analysis-sonarcloud-android.yml`)

### Problem 1: `Could not find game-activity`
**Rozwiązanie:** Dodano opcję `OTC_SKIP_GAME_ACTIVITY` w `testyy/src/CMakeLists.txt`:
```cmake
if(NOT OTC_SKIP_GAME_ACTIVITY)
  find_package(game-activity REQUIRED CONFIG)
endif()
```
Workflow: `-DOTC_SKIP_GAME_ACTIVITY=ON`

### Problem 2: `OPENSSL_INCLUDE_DIR NOTFOUND` + `absl::log_internal_check_op not found`
**Rozwiązanie:** Dodano opcje `OTC_ENABLE_OPENSSL` i `OTC_ENABLE_ABSEIL` w CMakeLists.txt:
```cmake
option(OTC_ENABLE_OPENSSL "Enable OpenSSL (cryptographic library)" ON)
option(OTC_ENABLE_ABSEIL "Enable Abseil (Google C++ library)" ON)
```
Workflow: `-DOTC_ENABLE_OPENSSL=OFF -DOTC_ENABLE_ABSEIL=OFF`

### Problem 3: `Vorbis::vorbis not found`
**Błąd:** Wszystkie zależności Android były hardcoded bez sprawdzania flag
**Rozwiązanie:** Wszystkie zależności są teraz warunkowe z generator expressions:
```cmake
$<$<BOOL:${TOGGLE_FRAMEWORK_SOUND}>:Vorbis::vorbis>
$<$<BOOL:${OTC_ENABLE_LZMA}>:LibLZMA::LibLZMA>
$<$<BOOL:${OTC_ENABLE_PUGIXML}>:pugixml::pugixml>
$<$<BOOL:${OTC_ENABLE_FMT}>:fmt::fmt-header-only>
$<$<BOOL:${OTC_ENABLE_PROTOBUF}>:protobuf::libprotobuf>
# etc.
```

### Problem 4: Odwrócona logika `TOGGLE_FRAMEWORK_SOUND`
**Błąd:** `$<$<NOT:$<BOOL:OFF>>:...>` = TRUE (linkuje gdy nie powinno)
**Rozwiązanie:** Zmieniono na `$<$<BOOL:${TOGGLE_FRAMEWORK_SOUND}>:...>` (linkuje tylko gdy ON)

### Problem 5: `cmake_pch.hxx.pch not found`
**Błąd:** SonarCloud próbuje odczytać precompiled header który nie istnieje
**Rozwiązanie:** Dodano `-DTOGGLE_PRE_COMPILED_HEADER=OFF` do workflow

## 💡 Lessons Learned

1. **GCC14 jest bardziej restrykcyjny** - wymaga explicit includes i konwersji
2. **Generator expressions w CMake** - `$<$<BOOL:VAR>:target>` dla warunkowego linkowania
3. **SonarCloud ≠ pełny build** - wystarczy `compile_commands.json`, nie potrzeba wszystkich zależności
4. **Nazwy opcji mogą być mylące** - `TOGGLE_FRAMEWORK_SOUND=OFF` znaczy "wyłącz dźwięk"
5. **Precompiled headers** - wyłącz dla analizy statycznej

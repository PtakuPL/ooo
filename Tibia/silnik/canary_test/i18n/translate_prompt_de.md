# 🌍 PROMPT TŁUMACZENIA NA JĘZYK: NIEMIECKI

## Instrukcje dla agenta LLM

Przetłumacz poniższe teksty z angielskiego na **niemiecki**.

### ⚠️ ZASADY (BARDZO WAŻNE!):
1. **Komendy w 'apostrofach'** - NIE TŁUMACZ! (np. 'trade', 'job', 'yes', 'no', 'buy', 'sell')
2. **Zmienne w {nawiasach}** - zostaw bez zmian (np. {player}, {amount}, {npc})
3. **Formatowanie |PIPE|** - zostaw bez zmian (np. |PLAYERNAME|, |TIME|)
4. Tłumacz naturalnie, zachowując ton i styl postaci NPC

### Przykład poprawnego tłumaczenia:
```
EN: Hello adventurer! Ask me about 'trade' or 'job'. I have {count} items.
DE: Hallo Abenteurer! Frag mich nach 'trade' oder 'job'. Ich habe {count} Gegenstände.
```
